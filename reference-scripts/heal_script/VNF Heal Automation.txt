VNF Heal Automation
===================

This script is used to trigger the Heal operation for a specific VNF instance via the Tacker v2 API.

Prerequisites
-------------

#. OpenStack Environment

    A running OpenStack Tacker environment is required.
    Ensure tacker and openstack CLI clients are installed and configured.

#. VNF Instance

   A valid and instantiated VNF instance should exist in the system.

Configuration
-------------

All required input parameters are stored in the configuration file: vnf_config.conf

You must edit this file before executing the script. Here's what it includes:

.. code:: bash

    Keystone Auth
    KEYSTONE_URL=http://localhost/identity/v3/auth/tokens
    USERNAME=nfv_user
    PASSWORD=devstack
    USER_DOMAIN_ID=default
    PROJECT_NAME=nfv
    PROJECT_DOMAIN_ID=default

    VNF Heal API Details
    PROTOCOL=http
    HOST=<HOST_IP_ADDRESS>   # Where tacker server is running
    PORT=9890
    API_VERSION=v2
    VNF_INSTANCE_ID=<your-vnf-id>
    USER_AGENT=python-tackerclient
    API_VERSION_HEADER=2.0.0

    Optional Heal Parameters
    CAUSE=healing
    ALL_PARAM=false
    VNFC_INPUT=<VNFC_INPUT>

CAUSE: Reason for healing (optional)

ALL_PARAM: Include all resources for healing (true or false, must be lowercase)

VNFC_INPUT: Comma-separated list of VNFC Instance IDs (optional)

Script Execution
----------------

1. Make the script and config file executable

.. code:: bash

   chmod +x vnf_heal.sh
   chmod +x vnf_config.conf

2. Run the Heal Script

.. code:: bash

   ./vnf_heal.sh
